Ashish Rajput - Portfolio website

How to put this online for free (Netlify):
1. Go to https://app.netlify.com/drop
2. Unzip this folder, then drag the whole folder onto the page.
3. Netlify gives you a live link. You can rename it in Site settings,
   for example ashishrajput.netlify.app

To add a new video later:
- Put the .mp4 file in the "videos" folder.
- In index.html, copy one <article class="proj ..."> block inside
  the "bento" section and change the video path, title and text.
